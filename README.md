# 福祉データベース（全国対応・オフライン / SQLite）

インターネット接続なしで動作する、**ブラウザ完結型の SQLite データ基盤**です。
これまで作成してきたオンプレ・オフライン前提の各種アプリのデータを、
一つの SQLite データベースに集約・移行することを目的としています。

- **サーバー不要** — `index.html` をブラウザで開くだけで起動
- **インターネット不要** — SQLite 本体（WebAssembly）をリポジトリに同梱
- **CDN・外部通信ゼロ** — すべてローカルファイルで完結
- **データ移行に対応** — 既存アプリが書き出した CSV / JSON を取り込み、
  列の型を自動判定してテーブルを自動生成

---

## クイックスタート

### 方法 A：ダブルクリックで開く（最も簡単）

`index.html` をダブルクリックし、ブラウザ（Chrome / Edge / Firefox など）で開きます。
WebAssembly を JavaScript に埋め込んでいるため、`file://` でもそのまま動作します。

### 方法 B：簡易ローカルサーバー（推奨・複数ファイル配信が安定）

Python さえ入っていればオフラインで起動できます（インターネット不要）。

```bash
cd fukushi-nationwide-app
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

LAN 内の他端末からも参照させたい場合は、同じサーバーの IP:8080 にアクセスします。

## 使い方

### 1. データ移行（既存アプリからの取り込み）

1. 「📥 データ移行」タブを開く
2. 既存アプリで書き出した **CSV / JSON** ファイルをドロップ（またはクリックで選択）
3. 列の型（TEXT / INTEGER / REAL）が自動判定される — 必要なら変更
4. テーブル名・取込モード（新規作成 / 置換 / 追記）を選ぶ
5. 「この内容で取り込む」で SQLite テーブルに登録

`sample-data/` に動作確認用のサンプル（CSV・JSON）を同梱しています。

### 2. 基本スキーマの作成（任意）

ツールバーの「🏗 基本スキーマ作成」で、福祉アプリ向けの標準テーブル
（`都道府県` / `サービス種別` / `事業所` / `職員` / `利用者` / `サービス記録`）を作成し、
全国 47 都道府県マスタと主要サービス種別を投入します。
移行データの受け皿として利用できます（定義は `schema/schema.sql`）。

### 3. 査定・返戻 公表データ（厚労省・支払基金・国保中央会）

「📊 査定・返戻」タブ → 「公表データを投入」で、厚生労働省保険局・社会保険診療報酬支払基金・
国民健康保険中央会・内閣府（規制改革推進会議）が公表しているレセプト審査（査定・返戻）の
統計値を **出典付き** で取り込みます（定義は `schema/satei.sql`、データは `js/satei.js`）。

- `査定返戻_出典`：公表資料マスタ（資料名・発行元・URL）
- `査定返戻_統計`：全国・審査機関別の統計値（請求件数／査定件数／査定率／1万点当たり査定点数／返戻 等）
- `査定返戻_都道府県`：支部（都道府県）別の値
- `査定返戻_指標定義`：各指標の分子・分母の定義
- `査定返戻_事由マスタ`：査定事由・返戻事由のマスタ
  - 医科レセプト：増減点連絡書の事由記号 A〜K（支払基金「増減点連絡書・各種通知書の見方」）、
    国保連の縦覧・突合点検記号 J / T / Y、返戻内訳書の事由コード（L5000番台＝資格・記載、L6000番台＝傷病名等）
  - 介護保険：返戻（保留）事由記号 A〜E（国保中央会「介護給付費請求の手引き」）、
    4桁エラーコードの系統と主要コード（ABB0 / ADD0 / 12P0 / 12PA / 12QJ など）
  - 障害福祉：返戻エラーコードの系統と主要コード（EG03 / EJ16 / PQ28 / PR44 / EC01 など）
- `査定返戻_自院記録`：自院（自事業所）の査定・返戻を事由別に記録し、構成比を集計

タブでは全国水準の KPI、原審査 請求1万点当たり査定点数の推移、支払基金と国保連の横並び比較、
**自院の請求・査定実績を入力して全国水準と比較** する簡易ベンチマークを表示します。

収録している主な公表値（投入時点）：

| 項目 | 値 | 出典 |
| --- | --- | --- |
| 支払基金 原審査 査定率（令和2年3月審査分・医科歯科計） | 件数 1.10 % ／ 点数 0.255 % | 厚労省保険局「審査支払機関の現状と課題について」 |

支払基金「審査状況」（月次 ZIP）や国保中央会「審査支払業務統計」の最新値は、
`sample-data/査定返戻_追加テンプレート.csv` と同じ列構成の CSV を「データ移行」タブで
`査定返戻_統計` へ **追記** すれば反映されます（出典ID は `査定返戻_出典` に登録済みの
`SSK-STATS` / `KOKUHO-STATS` が使えます）。

> 事由別（返戻理由別）の全国件数は、医科・介護とも公的に公表されていません。
> そのため事由はマスタとして収録し、件数は「自院の記録」フォームで登録して集計する設計にしています。
> 介護給付費（国保連請求）の返戻・過誤の全国統計（都道府県別件数）も未公表のため含めていません。

### 4. 閲覧・検索・SQL

- 「📋 テーブル閲覧」：テーブル選択・全列横断検索・ページング表示
- 「⌨ SQL コンソール」：任意の SQL を実行（`Ctrl`/`⌘`+`Enter` で実行）
- 「🗂 スキーマ」：全テーブルの列定義と行数を確認

### 5. 保存とバックアップ

- **💾 保存**：ブラウザ内（IndexedDB）に保存。次回起動時に自動復元
- **⬇ ファイル書出**：`.sqlite` ファイルとして書き出し（バックアップ・端末間移送）
- **⬆ ファイル読込**：`.sqlite` ファイルを読み込んで復元

> 書き出した `.sqlite` は、DB Browser for SQLite などの標準ツールでもそのまま開けます。

## 技術メモ

- **SQLite エンジン**：[sql.js](https://github.com/sql-js/sql.js) v1.13.0（SQLite を
  WebAssembly にコンパイルしたもの）。ブラウザ内で完全な SQLite が動作します。
- **オフライン対応**：`vendor/sql-wasm-data.js` に WASM バイナリを base64 で埋め込み、
  `initSqlJs({ wasmBinary })` として渡すことで `fetch` を一切使わずに初期化します。
  これにより `file://`（ダブルクリック起動）でも動作します。
- **永続化**：作業中のデータは IndexedDB に保存。長期保管・移送は `.sqlite`
  ファイルの書き出し／読み込みで行います。
- **文字コード**：UTF-8。CSV の BOM、クオート内改行、タブ区切りにも対応。

## よくある質問

**Q. データはどこに保存されますか？**
ブラウザ内の IndexedDB（この端末・このブラウザのみ）と、任意で書き出す
`.sqlite` ファイルです。外部サーバーには一切送信されません。

**Q. 別の端末に移したい**
「⬇ ファイル書出」で `.sqlite` を保存し、移送先で「⬆ ファイル読込」してください。

**Q. 既存アプリのデータ形式が特殊です**
まず CSV / JSON に書き出してから取り込んでください。取り込み後は SQL コンソールで
自由に整形・結合できます。
